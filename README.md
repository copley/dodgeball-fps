# Dodgeball FPS

A six-hour Godot 4 pilot for a first-person dodgeball game.

## Pilot goal

Prove the core loop:

1. Move and look in first person.
2. Pick up a ball.
3. Charge and throw it with projectile physics.
4. Hit a target.
5. Catch an incoming ball during a short timing window.
6. Dodge laterally.
7. Reset the round.

## Scope

The pilot uses one grey-box court, one player, one ball, and one stationary target or simple bot. It excludes multiplayer, polished art, progression, complex AI, menus, and production release work.
