# Preliminary Interactive Smoke Test

## Test type

Preliminary three-round interactive smoke test

## Round results

1. Bot won
2. Bot won
3. Player won

## Observed behaviour

- Bot movement and throwing worked.
- Catching worked.
- Dodging worked.
- Automatic round reset worked after every round.
- Nothing broke or became stuck.
- Overall game speed felt okay.

## Assessment

- The basic one-human-versus-one-bot exchange loop works interactively.
- Both the player and bot can win rounds.
- Core actions are usable during ordinary play.
- Automatic round progression works across three consecutive rounds.
- No blocker was observed during this short session.

## Limitations

- This was only three rounds.
- It does not complete M8.
- Throwing quality, catch fairness, bot balance, visual quality, audio,
  performance metrics and long-session reliability were not fully evaluated.
- The required ten-round M8 play-test remains pending.
